# 分化偏好、训练法与每日目标

2026-10-27本地实现。画像“训练安排”里独立选择分化与组次训练法，也可让AI按画像选择。分化不是每周训练天数，5×5也不是一周练五天。没有将某本书全文导入知识库，以下为当前支持的产品编排格式，不是品牌训练体系的完整复刻或效果排名。

## 分化与训练日

| 选项 | 当前周模板覆盖 |
|---|---|
| 全身训练 | 全身训练日，可安排多次 |
| 二分化 | 上肢、下肢 |
| 三分化 | 推、拉、腿 |
| 四分化 | 胸、背、肩臂、腿 |
| 五分化 | 胸、背、肩、腿、手臂 |

当前可执行周期使用稳定的一周模板，需要一周覆盖全部分组；二至五分化分别至少2至5个训练日，多出的训练日可以重复分组。没有实现跨周滚动分化。客户端保存画像及服务端生成前检查天数冲突，明确要求修改画像，不偷偷替换明确选择的分化。

分类是训练编排范围，多关节动作可以跨组：面拉可用于拉/背与肩日，硬拉可用于拉/背与下肢日。不按单一肌肉标签生硬拒绝，也不允许把明显无关的腿举放在推日。当前默认自动候选范围和原动作ID不变。

## 支持的组次训练法

| 训练法 | 当前结构要求 |
|---|---|
| 常规固定组 | 每个动作使用统一的组数、次数、重量目标 |
| 主项5×5 | 每天明确一个5组5次主项，辅助动作使用各自组次 |
| 力量与增肌混合 | 仅指定主项3–6次，其余所有辅助动作均8–15次，至少一个辅助动作 |

上述为本应用可表示、可检查的格式，并非所有人的最佳组次建议。没有实现每组不同负重的顶组回退、递减组、完整5/3/1等协议，不仅贴标签假装支持。恢复周按已确认模板降低组数，显示训练法来源及恢复提示，不冒充仍做完整5组。

计划仍结合力量表现、时间、器械、恢复与限制制定；有效RM上限、空重量拒收、近期不适与原进阶门槛保留。增加次数不能破坏方法约束：5×5主项不能在保留标签时自动变5×6，混合主项和辅助动作同样保留次数范围。原计划保留、记录不会因调整失败而丢失。

每次生成的分化候选按实际天数与可用动作裁剪，动作ID和方法枚举与校验保持一致。AI安排时提示优先简单可执行的常规组，明确偏好仍须遵守。候选违反规则会带具体错误自动校正一次，再完整校验基础周、未来周和负荷；两次均失败则返回原因与诊断编号，不放宽训练法或重量规则。校正前检查资料和授权修订，无效候选不持久化。详见[AI计划](AI_PLANS.md)。

## 页面和数据

先显示实际分化、周数、训练频率和每一天的部位/目标/训练法/时间/动作数；按天展开主项、辅助动作、重量组次、休息、目标余力和负重来源。制定理由、热身恢复及完整周期按需展开，风险提示另列。当前计划与新草稿沿用同一展示；编辑后的预览使用待保存动作和目标，重新生成清除上份草稿的说明修改。

画像字段：`training_split`与`training_method`，通过既有`PATCH /api/coach/profile`保存。计划新增`split_type`、`training_program_version`；每个训练日包含`focus/session_goal/training_method/primary_exercise_id`。没有新增表或迁移，仍存owner隔离JSON记录。API兼容已有计划；客户端省略已有日元数据时由服务端保留，修改当前周不重写未来周；新AI生成及未来周均校验完整目标、分组覆盖、动作范围与方法组次。

旧已保存计划没有这些字段时显示“旧计划未记录”，不猜测填充；旧未启用草稿需要重新生成后确认。画像偏好变化使旧草稿失效。手工编辑可修改该日目标/训练法，必须确认保存；方法标签与实际组次冲突时拒收。

实现：`backend/training_program.py`、`app.py`、`coach.py`、`periodization.py`与`progression.py`；Flutter `training_plan_overview.dart`、`profile_setup.dart`、`user_plan_editor.dart`、`cycle_plan_panel.dart`。测试与当前本地交付见[DEV_STATUS](DEV_STATUS.md)。

公开原则参考：[ACSM 2026更新](https://acsm.org/resistance-training-guidelines-update-2026/)、[ACE分化训练编排](https://www.acefitness.org/continuing-education/certified/may-2024/8632/the-ace-workout-builder-for-split-routines/)。这些来源不等同于对本应用具体三种格式、跨动作重量或每个个体处方的专业验收；本轮没有绕过知识发布门槛或激活新知识包。
