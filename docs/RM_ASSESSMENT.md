# 用户计划与RM评估

当前训练计划由AI根据已保存画像和有效RM生成草稿，用户核对、编辑后确认启用；也可手动维护训练日、动作变式、重量、组数、次数与休息时间。所有保存均为新版本，可先评估草稿；负荷评估本身不修改用户计划。当前实现与生成/确认流程见[AI_PLANS](AI_PLANS.md)。

2026-10-25起，生成AI计划必须先补齐胸、背、腿各一个熟悉动作的真实表现，允许杠铃、哑铃、固定器械等支持的变式。数据用于估计大致能力和起始负重，不生成统一力量等级或实测RM。新AI计划及各周目标均不得留空重量；来源分为同动作有效RM、同动作实际表现参考、部位力量背景估计，后两项标注首训需校准。不采用固定跨动作比例或跨器械公斤数等价关系。资料不足时回画像补齐，模型输出空重量时返回错误。详见[力量画像](STRENGTH_PROFILE.md)。

同动作首次建议不超过报告的实际重量；同重量不要求更多次数。有同动作有效RM时继续执行原RM上限。其他动作的数字是模型提出的待核对计划目标，不是测量结果或专业验证的精确处方。普通训练、三部位表现和模型建议均不自动创建RM；计划目标也不自动成为已完成训练。当前没有自动选重校准器，用户首训热身核对后可编辑目标、记录实际表现；原有自动进阶门槛保持。已保存历史计划不重写，旧未启用草稿需按新资料重新生成。

RM输入：动作变式、重量（含杠铃）、最大完成次数1–10、测量日期、是否确认最大次数。1RM作为用户实测报告值；2–10RM用NSCA通用次数表换算估算1RM。普通训练组或未确认的次数不作为RM基线。用户可填写已有数据，无需为使用产品专门进行极限测试。

当前参考：1–10次依次对应100%、95%、93%、90%、87%、85%、83%、80%、77%、75%。估算1RM = 用户RM重量 / 对应比例。计划负荷 = 计划重量 / 1RM参考值。超过1RM参考值或超过对应次数的通用参考时给出复核提示，不自动降低重量。

来源：[NSCA Training Load Chart](https://dxpprod.nsca.com/contentassets/61d813865e264c6e852cadfe247eae52/nsca_training_load_chart.pdf)。次数与1RM关系存在个体及动作差异，不能从RM单独确定组间疲劳、计划合理性或受伤风险。

同动作基线取测量日期最新的一条，同日取录入最新的一条。超过90天暂停评估是开发阶段的数据新鲜度规则，需专业审核。动作不匹配、缺少或未确认RM、未来日期与训练限制会分别处理。计划每组超过10次仅显示相对负荷，当前不外推次数匹配。

饮食目标独立根据当前画像计算，不依赖训练计划。修改画像后营养目标自动更新。
