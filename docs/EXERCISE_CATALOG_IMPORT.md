## 分类与使用

`backend/exercise_taxonomy.py`提供32类关节/功能运动标签，覆盖肩、肩带、肘、前臂、腕、手指、髋、膝、踝足、躯干、颈椎及多关节组合/静态活动。

一个动作可归入多个类别，例如卧推同时属于肩水平内收和肘伸展。动作库与计划编辑器均按这些标签过滤，并与训练部位联动。负重与自重仍使用独立类型字段；另将有氧、活动度/拉伸条目单独标记，避免把自行车等器械误当公斤负重训练。引体架、墙面、椅子等支撑物不自动意味着额外负重。

所有新增分类均为确定性规则推断，不宣称经过专业审核。47条名称不明确的条目使用目标肌群辅助映射，并显式标为needs_review；全部外部教学内容保留imported_unreviewed状态。名称使用可解释的术语替换生成中文/中英名称，英文原名始终保留，未宣称完成逐项中文编辑。

动作全部可浏览检索，外部负重条目可在计划编辑器手动选择和记录。Agent通过search_exercises检索完整库。AI自动生成计划目前仍使用已有项目/用户维护候选集，避免把千余条未审核数据塞进提示词；这不影响完整库的手动选择。动作分析上下文携带分类及来源状态；新条目没有自动新增实时检测器、观察点、合格角度或风险阈值。

## 重建与兼容

运行：`.venv/Scripts/python.exe scripts/import_exercise_catalog.py`。首次拉取固定提交的906帧，随后使用`.tools/exercise-import/pinned`缓存。`--skip-media`只重建数据，不改已有素材。

运行时将生成seed与旧seed一起批量补入数据库。重复启动幂等，已编辑/停用条目不会被覆盖或恢复；训练、计划、RM历史不会改写。修改导入规则后，已入库条目不会被静默覆盖，需准备显式审核迁移。

`/api/catalog?extended=true`只给外部条目发送计划筛选所需字段，完整教学文案通过分页动作库读取，避免登录时重复传输数MB文案。基础库与已评测知识库分开管理，外部数据不会直接冒充已发布科学证据。
